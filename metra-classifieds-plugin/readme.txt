== Description ==
Minimal, stable classifieds system with custom post type (mc_listing),
taxonomy (mc_category), frontend submit/edit forms and dashboard.

== Installation ==
1. Upload the ZIP via WordPress → Plugins → Add New → Upload Plugin.
2. Activate.
3. Required pages are created automatically.
4. Use provided shortcodes where needed.
